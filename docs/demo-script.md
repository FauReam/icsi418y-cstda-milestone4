# Four-minute demonstration plan

Target: about 4:15. Record the running app, with captions, on-screen labels, or narration identifying each story. Show only stories verified as Complete in the final report. Use a synthetic account and do not capture passwords, developer secrets, or unrelated browser content.

| Time | Workflow and story label | Show action and observable saved result |
|---|---|---|
| 0:00–0:20 | Title, team and login (NFR-06) | Identify CSTDA / Team 03 and log in. Explain the unified calendar and task list. |
| 0:20–0:55 | View calendar — UC-01 / US-01 | Navigate months, select an event date, read agenda titles/times, then select an empty date. |
| 0:55–1:30 | Organize by tabs — UC-05 / US-04 | Create Work with a color. Save an event in Work, show its absence under Academic and presence under All. |
| 1:30–2:20 | Manage event — UC-03 / US-05 | Show title/date/time validation briefly. Save a valid event, edit its details and tab, show the updated agenda and changed membership. Delete a disposable event after confirmation and show its removal. |
| 2:20–3:00 | Color coding — UC-02 / US-02 | Change a tab color and show an inherited event updating. Give one event an override, change the tab again and show the override persists. Clear it to restore inheritance. Point out an unaffected unrelated event. |
| 3:00–3:50 | Task workflow — UC-04 / US-03, US-06 | Create a task, edit priority among High/Medium/Low, and show labels. Complete a task; show checkbox, strike-through and Completed. Edit and delete a disposable task; verify another task remains. |
| 3:50–4:15 | Persistence and close | Refresh to show saved events/tasks. State the report’s measured completion fraction, with stretch stories excluded. |

Before recording, prepare a few short, clearly titled demo events and tasks, and rehearse the whole workflow. If the recording exceeds five minutes, shorten narration rather than omit evidence for a story marked Complete. Save with base name `Team03- Milestone 4- Demo` and the selected video extension.
